# Eva Mod - Biome NPCs

Friendly, immortal biome NPCs for **Minecraft 1.21.1 (NeoForge)**.

## Download

Go to **[Releases](https://github.com/developer-az/eva-mod/releases)** and download the latest `.jar`.

## Install

1. Install [NeoForge for Minecraft 1.21.1](https://neoforged.net/)
2. Put the jar in your `.minecraft/mods` folder
3. Launch the NeoForge 1.21.1 profile

## Features

- Biome-themed NPCs with jobs, personalities, and daily routines
- Dialogue, gifts, memory, and daily-rotating trades
- Cute procedural houses that generate in the world
